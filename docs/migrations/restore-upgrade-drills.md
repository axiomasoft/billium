## Preflight

**PLAN1.P9.7 · D59 / D71 · drill operator.** Run `scripts/drills/integration-migration.sh` with PHP 8.4, PostgreSQL 16 or newer, `pg_dump` and `pg_restore` on the disposable, role-separated test stand. The runner uses the repository's PostgreSQL test connection settings and requires a database name ending in `_test`. Its tests reset fixture tables and create disposable restored databases on this stand. The provider and authority ports use sanitized repository fixtures. Run all gates with the default invocation, or use `--scenario MGATE-06` to run the three counter variants and worker restart controls. Pass `--report` the destination allocated by the workspace evidence resolver.

**MGATE-01 and MGATE-11 · D52 / D58 / D62 / D63 · source and target operators.** Bind the exact installation, environment, seller, books, entity set and source/target OwnerSession generations. Pin catalog, selection and retention before export. Close source admissions for UI, API, cron, collection, import, admin, background and direct permitted writers. Drain admitted roots and verify the source seal and the external SourceFreezeCertificate. Export the immutable snapshot token and digest with a safe `(tx_id, id)` cursor below the committed horizon. Bind that checkpoint, live lease, scope, lineage and per-seller/currency reconciliation to the manifest. A wrong or expired freeze, lease loss, changed selection, catalog or lineage, invalid snapshot or checksum discrepancy keeps the target in recovery.

## Apply and activate

**MGATE-02, MGATE-04 and MGATE-07 · D25 / D52 / D58 / D63 · target operator.** Stage the exact target attachment in recovery. Verify the snapshot and the selected retained tail. Replay with stable source fact and economic revision identities and keep durable dispositions for every item. Adopt the terminal cursor atomically with reconciliation after confirming per-seller/currency counts, minor-unit totals and digests. Include obligations, allocations, actual effects, reservations, corrections, receipts, mappings and tombstones. The recovery drill interrupts adoption and exercises provider facts and downstream deliveries committed after the backup. Preserve original command and delivery identities so replay cannot repeat the provider effect, allocation or downstream export.

**MGATE-03, MGATE-05 and MGATE-06 · D26 / D54 / D58 / D62 · deployment authority.** Activation is a separate privileged action. Require authenticated RetirementProof for the predecessor and an unexpired scoped ActivationCertificate for the selected lineage and target deployment, bound to the verified manifest and receipt. Recheck source exclusion, target scope, unresolved requests, provider inventory where applicable and feed dispositions. A failed activation leaves the target in recovery. A normal worker restart or scale-out uses a fresh trusted process token for the same active OwnerSession. A deployment transfer, restored or cloned attachment, or continuity loss needs recovery. Lower, equal and greater commit counters remain diagnostics. The equal fixture dumps after B commits `n+1` while A's `n` is still uncommitted. The greater fixture adds only diagnostic activity to that incomplete copy.

## Abort, resume and repair

**MGATE-03 and MGATE-04 · D54 / D58 / D62 · source and target operators.** Before aborting the handoff, fence and drain the target and obtain authenticated proof it made zero monetary commits and external effects and cannot reacquire admission for that handoff. Include recovery applies when establishing the first write. Only then resume the source through explicit retirement and activation in a new epoch. After the first target commit or effect, keep the old source sealed and resume the target in recovery or arrange a separately certified reverse handoff. Release never authorizes a successor.

**MGATE-02, MGATE-05, MGATE-07 and MGATE-11 · D26 / D31 / D52 / D58 / D63 · recovery operator.** On interruption, resume from durable item dispositions and the adopted cursor. Rebootstrap on retention loss or a changed selection. Repair discrepancies through the owning APIs with authenticated original facts and preserve the original executor, account, binding, command key and digest. Resolve an accepted unknown by lookup or reconciliation with its original executor. Route refunds to the original charge owner. Keep unresolved work visible when proof or credentials are unavailable.

**MGATE-08, MGATE-09 and MGATE-10 · D21 / D25 / D55 / D56 · module and schema owners.** Expand before rolling out workers, rehearse the mixed window and restart interrupted backfill on a sanitized clone. Unsupported operation kinds and statuses must fail before egress. Reverting worker code keeps imported monetary facts and their bindings intact. Stop new work by draining and preserve pending custody, original-owner refunds where still authorized, and history. Advance retirement only after the owning evidence reader verifies blockers under the module barrier. A missing historical driver or revoked original-account credential with unresolved work blocks retirement and uninstall. Inspect the read-only uninstall preview and retain the receipts, source mappings, tombstones and binding history.
